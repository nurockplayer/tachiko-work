# Tachiko Work Mission

## Purpose

Tachiko Work exists to help people regain ownership of their documents, data, and computation.

This project is not only about building a better Office application.

It is about creating an open workspace where individuals, teams, and organizations are no longer permanently dependent on closed document ecosystems.

## The Problem

For decades, Word, Excel, and related Office tools have become the default language of productivity.

They are extremely successful products, but the world built around them creates long-term constraints:

- Important information is trapped inside proprietary formats.
- Documents are difficult to version-control and merge.
- Spreadsheets are forced to act as databases, programs, and knowledge systems at the same time.
- Collaboration workflows often depend on centralized platforms.
- AI systems must interpret human-oriented files instead of working with structured meaning directly.

The problem is not that Office tools are bad.

The problem is that the model of work has evolved beyond what traditional Office formats were designed for.

## A Personal Motivation

The motivation behind Tachiko Work comes from a simple observation:

Almost everyone has experienced the frustration of Office documents.

This includes:

- personal users managing important information,
- family members sharing documents,
- coworkers collaborating on spreadsheets,
- developers managing structured data,
- designers balancing game systems,
- organizations maintaining decades of files.

People should not need to fight their tools in order to create, understand, and preserve their own work.

## The Vision

Tachiko Work aims to create a new foundation for digital work:

- Open formats instead of locked formats.
- Semantic models instead of historical file representations.
- Version control instead of opaque binary changes.
- Computation as a native capability instead of spreadsheet hacks.
- AI agents operating on meaning instead of simulating user actions.

## Beyond Office Replacement

The goal is not to recreate Microsoft Office feature by feature.

A simple clone would inherit the same limitations.

Instead, Tachiko Work aims to create a platform where:

- documents,
- spreadsheets,
- Markdown,
- structured data,
- computational notebooks,
- diagrams,
- AI workflows

are different views over the same underlying semantic model.

## Long-Term Mission

The long-term mission is to make productivity software more open, understandable, and extensible.

Microsoft Office should not disappear because someone builds a copy of Word or Excel.

It should become less necessary because people have a better foundation for creating and managing knowledge.

Tachiko Work is an attempt to build that foundation.
