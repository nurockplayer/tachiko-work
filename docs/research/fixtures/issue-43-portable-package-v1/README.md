# Issue #43 developmental package fixtures

Status: Superseded evidence

Superseded by: [ADR-0042](../../../decisions/ADR-0042-first-public-portable-package-over-roproj-v3.md)

The `empty.roproj/` files, `empty-package-v1.hex`, and associated
[Issue #43 probe](../../probes/issue-43-portable-package-v1.mjs) describe
unreleased package/v1 over roproj/v1. Their bytes are retained unchanged as
historical evidence, with no legacy-reader or preservation obligation for the
implementation. They are not vectors for the redefined first-public profile.
The [current spec](../../../specs/portable-package-v1.md) requires a new
byte-level golden vector in the replacement implementation PR.
