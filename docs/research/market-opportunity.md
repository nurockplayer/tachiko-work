# Market Opportunity

## Core thesis

The opportunity is not replacing Microsoft Office feature-by-feature.

The opportunity is creating a new standard for semantic documents:

- documents
- spreadsheets
- structured data
- computation
- AI operations
- Git workflows

## Initial wedge

Game development is selected as the first vertical because it has a clear pain point:

Designer workflow:

Excel / Sheets
→ CSV export
→ Engine import
→ Git separation

Tachiko Work combines these into one version-controlled workflow.

## Expansion path

1. Game development data
2. Technical documentation
3. AI-native knowledge workers
4. Scientific and operational data
5. General productivity

## Business model

Open source adoption drives distribution.

Revenue opportunities:

- Managed cloud
- Team collaboration
- Enterprise deployment
- Migration services
- AI services
- Support
- Marketplace
- Commercial licensing
