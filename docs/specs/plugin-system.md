# Plugin System Direction

## Goal

Tachiko Work should become an extensible platform, not a closed application.

## Plugin Categories

Possible plugins:

- import/export adapters
- renderers
- formula functions
- AI agents
- validators
- integrations
- game engine connectors

## Examples

Game development:

- Unity integration
- Unreal integration
- Godot integration

Knowledge work:

- GitHub integration
- documentation systems
- data connectors

## Design Principle

The semantic core should remain stable.

Extensions should build on top of stable contracts instead of modifying the foundation.

## Long Term Vision

A healthy ecosystem around Tachiko Work is more valuable than a large monolithic application.
