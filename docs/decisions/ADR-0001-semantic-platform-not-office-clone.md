# ADR-0001: Tachiko Work is a semantic platform, not an Office clone

Status: Accepted

## Context

A direct Microsoft Office or LibreOffice rewrite would inherit decades of compatibility constraints.

## Decision

Tachiko Work will focus on a semantic document model.

Office formats, Markdown, spreadsheets, and computational documents are projections over the same core model.

## Consequences

Prioritize:

- semantic correctness
- structured data
- AI-native operations
- extensibility

Do not optimize for blindly reproducing historical behavior.
