# ADR-0005: Game Development First Wedge

## Status
Accepted

## Context

Traditional spreadsheets create significant friction in game development balance workflows. Technical designers already work with structured data, formulas, version control, and iterative changes.

## Decision

The first commercial wedge for Tachiko Work is game development balance data.

The initial target users are:

- technical designers
- indie game developers
- small and medium game teams

The first showcase domain is:

- characters
- weapons
- items
- economy balance

## Consequences

Examples, documentation, and MVP validation should use game development scenarios.

This does not limit the long-term semantic workspace vision. Other domains can adopt the same foundation after the core model is proven.
