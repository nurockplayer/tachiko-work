# Open Source Community Plan

## Principle

Open source is a distribution strategy and ecosystem strategy.

## Community Goals

- Contributors improve the core platform
- Plugins expand capabilities
- Formats become interoperable
- Users become advocates

## Focus Areas

- Documentation
- SDKs
- Integrations
- Examples
- Developer tooling

## Success Metric

Not only GitHub stars, but active users, contributors, plugins, and real-world documents created with Tachiko Work.
