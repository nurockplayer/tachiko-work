# Developer Adoption Strategy

## Initial Audience

- Game programmers
- Technical designers
- Indie studios
- Tools engineers
- Open source developers

## Adoption Loop

```
Open format
    |
Git repository
    |
Collaboration
    |
More contributors
    |
Ecosystem growth
```

## Key Message

The goal is not to replace Excel immediately.

The goal is to make structured data a first-class software artifact.
