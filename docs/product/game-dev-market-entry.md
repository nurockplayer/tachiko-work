# Game Development Market Entry

## Thesis

The first market is not chosen because Tachiko Work is a game tool.

It is chosen because game development exposes the strongest need for version-controlled computational data.

## Existing Pain

```
Designer
  |
Excel / Sheets
  |
CSV export
  |
Engine import
  |
Git separation
```

The workflow separates design intent from engineering history.

## Tachiko Work Solution

- Git-native CLI workflow
- Typed game data
- Semantic diff
- Balance validation
- Engine integration

Current v0.1 remains CLI-first and does not include a spreadsheet UI.

## Long Term

Game development is the proving ground for a broader semantic workspace platform.
