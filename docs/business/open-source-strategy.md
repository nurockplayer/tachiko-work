# Tachiko Work Open Source Strategy

Status: Research

## Goal

Use open source as an adoption engine while building sustainable commercial services.

## Potential revenue

- hosted cloud collaboration
- enterprise deployments
- migration services
- AI services
- support
- commercial integrations
- ecosystem marketplace

## Principle

The core value should not only be source code.

Long-term advantages:

- ecosystem
- community
- integrations
- file format adoption
- trust
- official services

## Licensing topics to evaluate

Possible layers:

- open format specification
- permissive SDKs/adapters
- copyleft application/server components
- trademark protection
- commercial licensing

Final licensing decisions require separate legal review.
