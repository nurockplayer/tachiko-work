# Prototype Roadmap

The first prototype should prove that Git-native computational data is possible.

## Phase 0

Semantic core:

- Entity model
- Schema
- Formula evaluation
- Serialization

## Phase 1

Game data prototype:

- Spreadsheet UI
- Typed tables
- Validation
- Diff

## Phase 2

Git workflow:

- Branch support
- Semantic merge
- CLI tools
- CI integration

## Phase 3

Engine integration:

- Unity
- Unreal
- Godot
