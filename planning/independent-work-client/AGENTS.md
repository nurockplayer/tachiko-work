# Independent client preparation

Read the owning live Issue, then `docs/SPEC.md` and its upstream authority links.
The upstream Constitution, Accepted ADRs/specifications and applicable governance
outrank this provisional client design. Existing UI implementation is evidence,
not a design constraint. `docs/ACCEPTANCE.md` distinguishes authored seeds,
harness self-tests and real product evidence. This tree contains no production UI.
Use the live queue and its readiness decisions; a seed does not grant production
readiness. Preserve acceptance provenance and return material challenges to the
Steward. Use pnpm for JavaScript dependencies. Do not self-merge.
