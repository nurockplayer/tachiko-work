# TachikoWork(RustOffice)

An open semantic document and computational data platform.

TachikoWork(RustOffice) is not just an Office clone.

Its goal is to unify structured documents, spreadsheets, Markdown,
computational data, Git workflows, collaboration, and AI around a
modern semantic core.

## Initial Wedge

The first target market is game-development data and balancing:

- Git-native spreadsheets
- Typed schemas
- Semantic diff and merge
- Branch-friendly game data
- CI validation
- Unity / Unreal / Godot integration

## Status

Early product and architecture research.
