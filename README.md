# Tachiko Work

A Rust-native, Git-native and AI-native workspace for documents, spreadsheets, structured data, and computation.

## Vision

Tachiko Work is not an Office clone.

It is a semantic document platform where:

- documents
- spreadsheets
- Markdown
- structured data
- formulas
- collaboration
- AI agents

operate on a shared modern core.

Traditional tools separate these worlds:

- Word for documents
- Excel for computation
- Markdown for developers
- Git for version control
- AI as an external assistant

Tachiko Work explores a unified model where these are different projections of the same underlying data.

## Initial Wedge: Game Development

The first target market is game-development data and balancing:

- Git-native spreadsheets
- Typed schemas
- Semantic diff and merge
- Branch-friendly balance data
- CI validation
- Unity / Unreal / Godot integration

## Principles

- Semantic correctness over historical accidents
- Legacy compatibility belongs at system boundaries
- Open formats over vendor lock-in
- Git is a storage protocol, not a user interface
- AI should manipulate semantic models, not imitate users
