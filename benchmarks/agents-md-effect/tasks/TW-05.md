# Spike a resident Native/WASM workspace runtime

Work only from the supplied checkout and task context; external services,
current remote state, and descendant history are unavailable.

Produce executable, explicitly provisional evidence for whether Tachiko Work
can retain one Rust-owned semantic workspace behind a TypeScript Worker boundary
without creating a second source of semantic truth.

Keep the production crates unchanged except for evidence-only integration that
is strictly required. Keep the spike standalone, disposable, and clearly
separate from the production workspace; record its research conclusion in the
repository's existing research documentation area.

The spike must demonstrate:

- a resident Rust session owning the document, with explicit ordering or
  revision evidence that rejects stale command application;
- semantic commands and selective query/mutation results rather than ordinary
  whole-document round trips;
- the same production workspace engine executing natively and as real
  `wasm32-unknown-unknown` code;
- a TypeScript Worker client that retains no competing document mirror;
- fixed native/WASM parity observations for the same command sequence;
- a boundary benchmark comparing whole-snapshot/stateless traffic with resident
  command traffic, reporting medians and payload-size methodology;
- a portability audit for duplicated policy, host leakage, ABI lifetime risk,
  unstable DTO claims, and canonical-state drift.

Use one reproducible Node package-manager workflow with an explicit version and
matching lockfile; do not introduce overlapping package-manager state. Label the
ABI, message shape, internal serialization, synthetic generator, and benchmark
DTOs as throwaway evidence—not a public SDK or wire contract. Do not promote the
spike into the production workspace, add a second engine, freeze IPC/Worker
APIs, or claim browser performance from a Node-only probe.

Run the spike build, Rust tests, Node Worker/parity tests, portability audit, and
benchmark. Run the repository gate that proves production behavior is
unchanged. Report exact commands, results, measurements, and limitations.
