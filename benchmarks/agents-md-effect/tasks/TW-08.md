# Implement the accepted legacy direct-RO v1 persistence boundary

Work only from the supplied checkout and task context; external services,
current remote state, and descendant history are unavailable.

Bring the storage implementation into conformance with the accepted versioned
storage and canonical-representation contract. Preserve the shipped direct
`.ro` version-1 profile as historical compatibility; do not let the current
semantic model's serialization layout define that durable wire format.

The reader must own a strict byte-to-document pipeline: distinguish invalid
UTF-8 from invalid JSON, reject duplicate object members at every depth after
escape decoding, inspect only the minimal version envelope before decoding a
version-specific body, and fail closed on missing, malformed, or unsupported
versions. A recognized v1 body is closed-world recursively and must be
converted and semantically validated explicitly. Unsupported future bodies
must not be partially interpreted or rewritten.

The writer must emit the repository's canonical legacy-v1 bytes: UTF-8 without
a BOM, the accepted member and collection ordering, two-space structural
indentation, LF line endings, no trailing whitespace, exactly one final LF,
deterministic escaping, and exact Unicode scalar preservation without implicit
normalization. Preserve the frozen legacy numeric behavior; do not claim broad
JCS compliance or import later numeric policy into v1.

Provide one migration-facing v1 boundary that returns storage-owned validated
data only after the same strict byte/version guarantees. Do not add a permanent
storage semantic model, invent a new representation version, auto-upgrade on
read, or decide `.roproj`, package/container, diagnostics, runtime durability,
plugin, collaboration, or cloud-storage policy.

Add focused negative, canonical-byte, ordering, Unicode, compatibility, and
migration-boundary tests. Run the focused storage suite, the workspace checks,
and the complete release-equivalent gate. Report the exact commands and
results.
